# iPhone Duo 开售夜自动刷新脚本

2026-10-16 苹果中国官网 iPhone Duo 预购当晚用的 Safari 自动刷新脚本（macOS + AppleScript）。

- `night_watch.py`：最终版。倒计时 → 北京 19:59:30 开刷（2/4/12 秒固定节奏）→ 认出能买就停手、推到面前、响铃。
  认得维护页 / 排队页；刷新前和等待时常驻检查，不会刷掉已经能买的页面；按住右 Shift 或 Esc 1 秒在任何窗口强制关闭。
- `launch_watch.py`：早期版本，`night_watch.py` 复用了它的 AppleScript 零件。
- `desktop-launchers/`：桌面双击用的启动文件（演练、自检、紧急停止，以及停用的旧版）。
- `backups/`：开发过程中的备份和冻结副本。
- `待改清单-2026-10-13.md`：复查时列的问题清单和修改记录。

结果：下单成功。但开卖时多次看到首批日期、一点「加入购物袋」就被拦成英文 Page Not Found——
同一会话刷新太密可能会耗掉加购额度，下次建议刷新和加购分开会话。
